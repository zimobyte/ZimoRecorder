# Changelog

## 1.0.0
- Screenshot, screen recording (MP4) and GIF recording
- Window picker with highlight + free region selection
- Screenshot editor (line, arrow, text, blur, undo)
- Text recognition (OCR) from any region
- Main window, tray icon, notification cards that open the saved file's folder
- 15 interface languages, English by default
- Signed in-app updates from the publisher's own server
- Windows installer with desktop shortcut and optional "start with Windows"
